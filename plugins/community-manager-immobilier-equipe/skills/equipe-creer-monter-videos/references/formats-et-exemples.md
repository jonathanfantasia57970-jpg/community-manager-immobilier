# Dix dispositifs adaptables

Repère : FORMATS-VIDEO-2026.11.01.1.

Ces dispositifs orientent la conception ; ce ne sont ni des vidéos déjà produites ni des formats dont la performance est prouvée. Consulter la bibliothèque vivante et la matière réelle. Adapter durée, rythme et forme au canal. Un même dispositif peut servir publicité ou contenu organique, selon la promesse et la fin.

| Format | Déroulement | Matière et contrôle |
| --- | --- | --- |
| F01 — Une question précise | Question reconnue → réponse → exemple → conséquence | Face caméra ou voix ; conserver la nuance utile |
| F02 — Deux usages | Deux choix plausibles → critère → comparaison visible → décision conditionnelle | Rush enrichi de photos/plans ; aucune fausse opposition |
| F03 — Le détail qui compte | Montrer → expliquer l’usage → limite → vérification | Plan rapproché réel ; ne pas inventer un diagnostic |
| F04 — Une démonstration | Résultat attendu → étapes visibles → résultat réel → prochain geste | Capture/rush/produit ; pas de capacité simulée présentée comme réelle |
| F05 — Une objection examinée | Objection crédible → ce qui est fondé → réponse étayée → action | Présentateur ou schéma ; pas de client fictif présenté comme réel |
| F06 — Un bien, un usage | Usage recherché → preuves visuelles → compromis → contact/fiche | Médias du bien ; fidélité des volumes et caractéristiques |
| F07 — Un cas expliqué | Situation → options → faits déterminants → raisonnement → enseignement | Documents autorisés et anonymisés ; résultat réel ou fiction annoncée |
| F08 — Deux parcours graphiques | Question → chemins animés → différence → conseil | Formes, étapes, voix fournie ; données fictives signalées |
| F09 — Trois vérifications utiles | Enjeu → vérifications montrées → prochain geste | Captures/documents/annotations ; apporter un critère concret |
| F10 — Le mécanisme visible | Question → schéma progressif → exemple → limites → application | Motion calculé ; le mouvement aide à comprendre une relation |

Pour un tournage : retenir des idées à expliquer plutôt qu’exiger un texte récité, tout en fixant les formulations commerciales ou factuelles sensibles. Choisir les plans d’illustration avant de demander des prises supplémentaires.

Exemple illustratif de montage hybride : question face caméra sur deux maisons de même surface ; voix continue sur deux plans schématiques ; mise en évidence de deux/trois chambres ; retour au présentateur pour expliquer la conséquence. Ne pas en déduire un écart de valeur chiffré ni l’existence de deux mandats réels.

Exemple sans tournage : expliquer les étapes d’un service avec trois documents autorisés et une voix existante ; animer les éléments utiles et conserver les limites. Sans voix disponible ni budget vocal, une version graphique autonome peut convenir si le message reste compréhensible ; sinon signaler le manque au lieu de promettre une narration naturelle gratuite.
