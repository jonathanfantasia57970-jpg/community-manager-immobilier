# Sources primaires

Vérification initiale : 25 octobre 2026. Reconsulter les règles et outils quand ils conditionnent une décision. Ces références ne remplacent pas les sources propres aux faits d'un nouveau post.

- [Google : classement local](https://support.google.com/business/answer/7091) : pertinence, distance, notoriété ; aucune promesse de classement par cadence.
- [Google : règles des posts et médias](https://support.google.com/business/answer/7213077) : éviter les coordonnées dans le contenu et utiliser les champs autorisés ; les versions linguistiques observées divergent sur leur traitement.
- [Google : intégrité des contributions](https://support.google.com/contributionpolicy/answer/7400114) : avis authentiques, sans récompense ni sélection positive.
- [Google : contenus utiles](https://developers.google.com/search/docs/fundamentals/creating-helpful-content) : apport original, expertise et sources ; pas de longueur magique.
- [Google : antispam Search](https://developers.google.com/search/docs/essentials/spam-policies) : éviter pages locales interchangeables et production massive sans valeur.
- [Google : extraits](https://developers.google.com/search/docs/appearance/snippet) : une métadescription ne garantit pas l'extrait affiché.
- [Metricool : connexion GBP](https://help.metricool.com/how-to-connect-google-business-profile-to-metricool-qrvjw).
- [Metricool : publication GBP](https://help.metricool.com/schedule-and-post-on-google-business-profile-rgq1m) : formats et limites ; distinguer interface web et MCP.
- [Metricool : métriques GBP](https://help.metricool.com/google-business-profile-metrics-1bg2y) : données et retard de synchronisation.
- [Metricool : limites MCP](https://help.metricool.com/mcp-limits-and-plan-requirements-h72jg) : les fonctions de l'interface ne sont pas toutes exposées.
- [Metricool : Inbox](https://help.metricool.com/inbox-manager-how-to-manage-messages-and-comments-from-metricool-s9zze) : réponses aux avis dans l'interface, sans présumer une capacité MCP.

Pour les faits immobiliers français, privilégier selon le sujet Service-Public, Légifrance, ANIL, ADEME, Notaires, DVF, INSEE, Géorisques et sources locales officielles. Consulter réellement les pages pertinentes et conserver dates et périmètres. Distinguer explication générale et conseil individualisé.
