# Bibliothèque créative — v1

16 familles originales et 38 compositions modifiables créées le 31 octobre 2026. Ouvrir index.html pour parcourir la galerie hors ligne. Chaque dossier contient les SVG modifiables, les PNG, un aperçu de séquence, un blueprint JSON et son mode d’emploi. Les ZIP individuels regroupent ces mêmes éléments.

La bibliothèque vivante est dans Notion : CONFIG_SOURCE_PERSONNELLE

Les 52 exemples publicitaires tiers restent dans leur base d’origine ; ils ne sont pas inclus dans ce pack. Les compositions de ce pack sont originales et ne contiennent aucune photo tierce ni logo. Les champs et emplacements doivent être remplacés par des données et médias vérifiés.
