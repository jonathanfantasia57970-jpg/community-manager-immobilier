# Structure de la médiathèque

Une base mixte, reliée au profil du conseiller, regroupe photos, vidéos, portraits, logos et dérivés. Les gros fichiers peuvent rester dans son stockage autorisé avec un lien persistant. Ne pas recopier une URL signée expirante comme référence durable.

| Champ | Type et usage |
| --- | --- |
| Média et idée | Titre descriptif, sans récit inventé |
| Media ID / Business ID | Identifiants stables et propriétaire |
| Média / Original / Vignette | Fichier ou référence durable, original conservé |
| Type de média | Photo, Vidéo, Portrait, Logo, Audio, Dérivé |
| Source / Empreinte / Version | Provenance, dédoublonnage et version |
| Contexte confirmé / Faits visibles | Séparer déclaration et observation |
| Date de prise | Si connue ; ne pas confondre import et événement |
| Bien / Secteur / Tags | Données utiles à la sélection, minimum nécessaire |
| Droits / Restrictions / Échéance | Inconnu, autorisé pour préparation, autorisé pour diffusion ; preuve et limites |
| Durée / Analyse vidéo | Durée mesurée, timecodes regardés, audio écouté, couverture et inconnues |
| Parent / Transformation / Contrôle | Lien au média original et qualité du dérivé |
| Usages | Références vers contenus canoniques, états et preuves distincts |

Les avis clients, documents identifiants et personnes reconnaissables ne sont pas rendus publics par l’import. Les champs vidéo d’une photo restent vides. Ne pas utiliser le matériel d’un autre conseiller en repli. Les modèles graphiques se trouvent dans la bibliothèque, les portraits/photos/vidéos dans cette médiathèque ; un modèle peut référencer un média sans l’absorber.
